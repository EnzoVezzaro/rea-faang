# FAANG — Complete Product Directory

Understood. You want the actual product names written out in the document, not hidden behind links like “Google products” or “AWS products.” Each company should have its own comprehensive inventory, with products grouped by category and direct URLs visible wherever possible.

One important distinction: FAANG portfolios contain hundreds of products, services, APIs, developer tools, hardware products, and discontinued offerings. I’ll focus on current and recognizable product families, include official URLs, and distinguish major products from tools, frameworks, and services. A literally exhaustive inventory changes continually, so the official catalogs remain the reference for completeness.

### How I'd structure the directory for REA

If the goal is to use these companies' products and branding in the REA website or design system, maintain a structured inventory with one entry per product:

- `company`: Google, Apple, Amazon, Netflix, or Meta.
- `product`: exact official product name.
- `category`: AI, cloud, developer tools, hardware, consumer software, media, and so on.
- `official_url`: direct product URL.
- `logo_url`: official brand asset, where available.
- `status`: active, legacy, discontinued, or unverified.
- `product_type`: product, service, API, framework, model, hardware, or subsidiary.
- `last_verified`: date the entry was checked.

This makes the directory useful for research, navigation, logo collections, and implementation instead of leaving it as a large, unmaintainable Markdown list.
