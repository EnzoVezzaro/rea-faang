## What it is

Safari is Apple’s proprietary browser; its rendering engine, WebKit, is open source under BSD and LGPL licences.

## Core capabilities

- Web rendering via WebKit
- Energy-efficient engine, privacy features
- Integration with Apple platforms

## Existing open source

| Project | License | What it covers | Notes |
|---|---|---|---|
| [WebKit](https://webkit.org/) | BSD-2-Clause / LGPL-2.1 | The open-source engine Safari is built on. | Engine, not a browser product. |
| [GNOME Web (Epiphany)](https://apps.gnome.org/Epiphany/) | GPL-3.0 | A GTK browser built on WebKitGTK. | An open WebKit browser. |
| [Firefox / Chromium](https://www.mozilla.org/firefox/) | MPL-2.0 / BSD-3-Clause | Independent open browsers. | Different engines entirely. |

## Gap

Safari’s UI, Apple-platform integrations and some DRM/media modules are proprietary; only the engine is open.

## Verdict

Partial. The engine is open source and open WebKit browsers exist; the Safari product itself is pending to open-source.
