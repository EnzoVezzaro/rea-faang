# iOS (`apple-ios`)

## What it is

iOS is Apple’s proprietary mobile operating system for iPhone: kernel, frameworks, App Store and system apps, all closed source.

## Core capabilities

- Mobile OS runtime and app framework
- App Store distribution and sandbox
- Deep hardware/software integration

## Existing open source

| Project | License | What it covers | Notes |
|---|---|---|---|
| [postmarketOS](https://postmarketos.org/) | GPL-2.0 | A real Linux distribution for phones. | A different OS, not an iOS replacement. |
| [Ubuntu Touch](https://ubports.com/) | GPL-3.0 | Touch-oriented Linux for phones. | Different platform and app ecosystem. |

## Gap

No open-source project reimplements iOS; mobile Linux is an adjacent platform and does not run iOS software or hardware.

## Verdict

Pending to open-source. No verified open-source alternative to iOS itself.
