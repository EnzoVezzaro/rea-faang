## What it is

WhatsApp is Meta’s end-to-end encrypted messaging app: one-to-one and group chat, calls, media and status, built on a proprietary centralised service.

## Core capabilities

- End-to-end encrypted messaging and calls
- Group chats, media sharing, status
- Multi-device sync

## Existing open source

| Project | License | What it covers | Notes |
|---|---|---|---|
| [Matrix / Element](https://element.io/) | Apache-2.0 | Federated, end-to-end encrypted messaging; self-hostable. | The main open alternative. |
| [SimpleX](https://simplex.chat/) | AGPL-3.0 | Private messenger with no user identifiers. | Strong metadata privacy. |
| [Signal](https://signal.org/) | GPL-3.0 (client) | Client is open source. | Server is not open source. |
| [XMPP (Conversations)](https://xmpp.org/) | Apache-2.0 / GPL-3.0 | Open federated messaging protocol. | The older federated standard. |
| [Briar / Revolt](https://briarproject.org/) | GPL-3.0 / AGPL-3.0 | Peer-to-peer and community chat. | Specialised alternatives. |

## Gap

Network effects and the multi-billion-user contact graph are not reproducible; the protocol and clients are open.

## Verdict

Available. Federated and P2P open messengers cover the function.
