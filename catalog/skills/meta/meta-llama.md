## What it is

Llama is Meta’s family of large language models, released as downloadable weights under the Meta Llama Community Licence (open weights, not an OSI licence).

## Core capabilities

- General-purpose text generation and reasoning
- Instruction-tuned and multimodal variants
- Self-hostable weights

## Existing open source

| Project | License | What it covers | Notes |
|---|---|---|---|
| [Mistral (Apache-2.0 models)](https://mistral.ai/) | Apache-2.0 | Apache-2.0 licensed model family. | True OSI-licensed alternative. |
| [Qwen](https://github.com/QwenLM/Qwen3) | Apache-2.0 (many variants) | Open-weight model family. | Licence varies by variant. |
| [Falcon / OLMo](https://allenai.org/olmo) | Apache-2.0 | Permissively licensed open models. | OLMo is fully open (data + code). |
| [Ollama](https://ollama.com/) | MIT | Local runner for open weights. | Runtime, not a model. |

## Gap

Llama’s licence is not OSI open source and carries use restrictions; fully open model families exist but at differing capability.

## Verdict

Partial. Llama is open-weight, and genuinely open-source-licensed alternatives (Mistral Apache-2.0, OLMo) exist — hence no single "pending" project.
