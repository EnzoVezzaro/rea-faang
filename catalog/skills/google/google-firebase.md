## What it is

Firebase is Google’s app development platform: a realtime database, auth, storage, hosting, cloud functions, messaging and analytics behind one SDK.

## Core capabilities

- Realtime/firestore database and offline sync
- Authentication, file storage, hosting
- Cloud functions, push messaging, analytics

## Existing open source

| Project | License | What it covers | Notes |
|---|---|---|---|
| [Supabase](https://supabase.com/) | Apache-2.0 | Postgres-based backend with auth, storage, realtime, functions. | Closest drop-in in scope. |
| [Appwrite](https://appwrite.io/) | BSD-3-Clause | Self-hostable backend: auth, database, storage, functions. | Feature-complete alternative. |
| [PocketBase](https://pocketbase.io/) | MIT | Single-binary backend with realtime and auth. | Small and embeddable. |
| [Parse Platform](https://parseplatform.org/) | BSD-3-Clause | Open app backend (the original Firebase competitor). | Mature, self-hosted. |

## Gap

Firebase’s managed scale, its proprietary SDK surface and vendor-hosted extensions have no single open equivalent.

## Verdict

Available. Multiple mature, self-hostable backends cover the core.
