The mission

World-class software, whatever you earn or where you live.

Modern software is concentrated in a few companies. Subscriptions rise, features vanish, services shut down, data gets hard to move. Open source is another path — one where the code, the data, and the roadmap are yours to see and change.

We are not building one application. We are building an ecosystem of independent alternatives, one company at a time, one product at a time, one feature at a time.

  • Free access — no mandatory subscriptions
  • Open source — inspect, modify, improve
  • User ownership — local-first and portable
  • Interoperability — open standards first
  • Community-driven — contributors set priorities
  • Agent-assisted — AI accelerates, humans verify

How we build

Investigate. Understand. Reimplement. Verify.

A repeatable engineering workflow, run by people and agents together, grounded in public evidence.

  1. 01

    Investigate

    Study publicly observable behavior, official docs, and published protocols.

  2. 02

    Understand

    Document behavior as specifications, data models, and testable acceptance criteria.

  3. 03

    Reimplement

    Build an independent implementation — clean room, no proprietary code or assets.

  4. 04

    Verify

    Test correctness, usability, security, and interoperability against the spec.

  5. 05

    Release

    Publish source, docs, and reproducible builds — then improve in the open.

Agents do the heavy lifting; verification does not. An environment built on ace/v1 coordinates researcher, architect, frontend, backend, tester, reviewer, and documenter roles. A change is only done when a command proves it.
