At a glance

Google Chrome is Google’s Chromium-based web browser, bundling the Blink engine with proprietary Google services (sync, telemetry, DRM).

Catalog categories: browser.

Catalogued capability areas: - Web rendering (Blink) and high-performance JS (V8) - Multi-process sandboxing, devtools - Account sync and extension ecosystem

This summary reflects the catalog record, not a complete product specification. Verify intended users, end-to-end workflows, supported platforms, edge cases, data handling, and constraints against cited sources. Treat capability labels as research leads until that verification is complete.

  • Web rendering (Blink) and high-performance JS (V8)
  • Multi-process sandboxing, devtools
  • Account sync and extension ecosystem

4 candidate projects in the landscape. A candidate may cover all, part, or none of what Google Chrome does — read the coverage and gaps below.

Chromium ↗

BSD-3-Clause

The open-source browser Chrome is built from.

No Google sync/branding/DRM by default.

Firefox ↗

MPL-2.0

Independent engine (Gecko) and full browser.

A separate engine, not a Chromium fork.

Brave ↗

MPL-2.0

Chromium browser with built-in ad/tracker blocking.

Some bundled services are proprietary.

LibreWolf ↗

MPL-2.0

Hardened Firefox fork.

Privacy-focused fork.
