At a glance

Microsoft Azure is Microsoft's public cloud platform for compute, storage, networking, data, AI and other managed services; it is a platform catalogue rather than one application.

Catalog categories: cloud, platform.

Catalogued capability areas: - Compute, containers, serverless and application hosting - Storage, databases, networking and integration services - Identity, security, monitoring and governance capabilities - Resource management, infrastructure as code and deployment tooling

This summary reflects the catalog record, not a complete product specification. Verify intended users, end-to-end workflows, supported platforms, edge cases, data handling, and constraints against cited sources. Treat capability labels as research leads until that verification is complete.

  • Compute, containers, serverless and application hosting
  • Storage, databases, networking and integration services
  • Identity, security, monitoring and governance capabilities
  • Resource management, infrastructure as code and deployment tooling

IaaS orchestration for private clouds.

Narrower service catalogue than a hyperscaler.

Coverage and gaps

Alternative coverage

Partial. Private-cloud IaaS is well covered; the managed-service breadth and operational model of a hyperscaler remain a research and integration problem, not a drop-in replacement.

The gap

OpenStack and CloudStack provide an IaaS control plane, but no open-source project verifies a comparable managed-service catalogue and global region footprint.
