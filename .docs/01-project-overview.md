# RAE FAANG - Project Overview

## Mission Statement
**Reverse Engineer Anything. Rebuild Everything. Open Source for Everyone.**

The mission: make the products of the world's biggest technology companies free, open source, and accessible to everyone.

## Vision
An ecosystem of open-source alternatives to FAANG products (Meta, Amazon, Apple, Netflix, Google) that gives users:
- Free access without mandatory subscriptions
- Open source code for inspection, modification, and improvement
- User ownership through local-first operation and data portability
- Interoperability via open standards
- Community-driven development priorities
- AI-powered development acceleration
- Long-term sustainability through community maintenance

## Product Scope
Five company focus areas with proposed product catalogs:

| Company | Product Families |
|---------|------------------|
| **Meta** | Social networking, messaging, communities, media sharing, collaboration, VR |
| **Amazon** | E-commerce, cloud infrastructure, developer services, streaming, digital assistants |
| **Apple** | Desktop/mobile experiences, productivity, creative apps, media services, device ecosystems |
| **Netflix** | Video streaming, content discovery, recommendations, media delivery, creator tools |
| **Google** | Search, maps, email, video, office productivity, cloud, developer tools, AI services |

## Development Approach
**Reverse engineer → Understand → Reimplement → Verify → Release and improve**

Using AI agents as development infrastructure:
- Research agents investigate product behavior
- Architecture agents create specifications
- Development agents build features
- Testing agents validate functionality
- Security agents inspect vulnerabilities
- Review agents evaluate code quality
- Maintenance agents identify issues

## Architecture Principles
- Modular by design with clear interfaces
- Open standards first
- Local-first where practical
- Security and privacy by default
- Cross-platform accessibility
- Testable implementations
- Sustainable maintenance

## Project Phases
1. **Foundation** - Organization, standards, workflow, first product selection
2. **First Working Alternative** - MVP implementation, tests, documentation
3. **Expand Catalog** - Additional features, shared infrastructure
4. **Agentic Development at Scale** - Multi-agent coordination, automation
5. **Open Ecosystem** - Connected products, community forks, self-hosting
